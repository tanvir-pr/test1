# Web-2-Midterm-1-A group

Solution for **Web-2-Midterm-1-A group** (Express + MySQL).

Replace `NEPTUN` at the top of both `app.js` files with your real Neptun code before submission. Zip folders as `YourName-Neptun.zip`.

## Exercise 1 (7 points)

Folder: `1-exercise`

```powershell
cd 1-exercise
npm install
node app.js
```

Open http://localhost:3000/exercise

- Name and Address text fields
- Country list: Hungary, Poland, Austria, Italy
- POST to the same URL and prints `Name:`, `Address:`, `Country:`
- Name and Neptun code on the first row

## Exercise 2 (14 points)

Folder: `2-exercise`

Create the `exercise` database in XAMPP phpMyAdmin with `exercise.sql`. Start MySQL first.

```powershell
cd 2-exercise
npm install
node app.js
```

Open http://localhost:4000

| Page | URL |
|---|---|
| Main list (Employees) | http://localhost:4000 |
| New record | http://localhost:4000/new |
| Edit | http://localhost:4000/edit/ID |
| Delete | http://localhost:4000/delete/ID |

## Exercise 3 (4 points)

Take `mainpage.jpg` and `edit.jpg` in the browser. The address bar, the name on the page, and a working app must be visible.
